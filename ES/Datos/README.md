# Datos

Este directorio contiene la documentación recopilada y analizada para las áreas de servicio y aparcamientos de vehículos pesados situados en las autopistas A7, A8 y A9 en Francia.

Cada subdirectorio incluye, según disponibilidad:

- Datos recopilados y clasificados.
- Análisis de reseñas públicas.
- Observaciones documentales.
- Informes en formato PDF.
- Archivos de trabajo y documentación complementaria.

## Corredores

- [A8](./A8/)
- [A9](./A9/)

## Nota

La documentación incluida en este directorio se basa exclusivamente en fuentes públicas, documentación institucional y material recopilado durante el desarrollo del proyecto.

Las incidencias recogidas no representan necesariamente la totalidad de los hechos ocurridos en cada emplazamiento analizado.
